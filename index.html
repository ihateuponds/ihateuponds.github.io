⚙️ my setup // linux & hardware bench

Here is what I daily drive for diagnostics, gaming, and school:

PRIMARY OS CachyOS Linux (Kernel 7.2, BORE CPU Scheduler)
WINDOW MANAGER Hyprland (Wayland Compositor)
SECONDARY OS Windows 11 Pro (Dual-boot on separate partition)
SHELL & TERMINAL zsh / foot / kitty
AUDIO ENGINE PipeWire + WirePlumber (low-latency Pro-Audio routing)
HARDWARE RIG AMD Ryzen 7 5700X + Radeon RX 6700 XT + 32GB RAM
💡 Why CachyOS Linux? I switched because I got tired of Windows bloat and forced updates. CachyOS is crazy responsive with the BORE kernel, gaming on Proton-GE with DXVK works great out of the box, and my desktop idles at barely 1.2GB of RAM.
