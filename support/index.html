Before submitting, gathering these commands speeds up diagnosis by 10x:

              
              

                [WINDOWS CRASHES]
                
Check eventvwr.msc → Windows Logs → System. Look for Event ID 41 (Kernel-Power) or BugCheck codes. Minidumps are stored in C:\Windows\Minidump\.

              


              

                [LINUX FREEZES / PANICS]
                
Run journalctl -p 3 -xb for priority error logs, or dmesg -T --level=err,warn to check GPU and kernel ring buffer errors.

              


              

                [THERMAL & HARDWARE]
                
Run HWiNFO64 (Sensors only) or MangoHud. Note CPU Tctl/Tdie and GPU Hotspot temp during crash load.
